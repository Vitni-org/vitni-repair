# Vitni 110-second pitch production plan

1. Prepare the pitch asset folder by reusing the licensed typefaces and adding repair photos that already ship with Vitni.
2. Build an editable, deterministic renderer for the approved 110-second storyboard. Use continuous camera moves and purposeful reveals to connect photo → repair steps → guide library → PWA → Paris help → partner roadmap.
3. Write the time-coded English talk track and scene cues, then render the H.264 MP4, original low-level music bed, poster, and contact sheet.
4. Review the render visually and check media duration/dimensions, then commit the video deliverables with a Conventional Commit.

No application code, dependencies, or product claims beyond the approved design are in scope.
