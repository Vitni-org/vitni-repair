# Vitni video production plan

1. Prepare the approved source assets: the comic Vitni mascot, repair photos, and local fonts.
2. Write a deterministic Pillow composition with five short motion scenes: hook, photo demo, repair steps, PWA, guide library, and Paris community/end card.
3. Render 300 frames and encode a 10-second 1920×1080 H.264 MP4; create a poster and contact sheet.
4. Review the output visually and with media metadata, adjust pacing/layout if needed, then commit source and outputs using a Conventional Commit.

No application dependencies or product code changes are part of this video task.
